# `public/` — ressources statiques

Ces fichiers sont copiés tels quels dans `dist/` par Vite.

| Fichier ou dossier | Rôle |
|---|---|
| `data/transactions.json` | 530 transactions fictives encodées |
| `data/salary.json` | Salaires, indices et SMIC du scénario fictif |
| `data/config.json` | Comptes neutres, soldes initiaux et couverture |
| `data/budgets.json` | Objectifs mensuels proposés au premier lancement |
| `manifest.webmanifest` | Métadonnées de l'application installable |
| `sw.js` | Cache hors ligne du shell et des données de démo |
| `favicon.svg`, `icons/` | Identité visuelle générique |
